    Standardized Bulk Import

    Import many component records through a controlled flow: template, upload, validation, review, confirmation, and result. No database changes occur before confirmation.

    01 Template Download the standard template and fill one row per Part Number.
    02 Upload Drag & drop the filled .XLSX, .XLS, or .CSV file.
    03 Validate Checked automatically: required fields, Shop, costs, and totals.
    04 Review Choose Add New Only or Add + Update, then check New, Update, Skip, and Error rows.
    05 Confirm Only valid rows are imported. Nothing changes before you confirm.
    06 Result See added, updated, skipped, and failed rows, and download the error report.
    ⇧
    Upload Component Database Drag & drop a standardized .XLSX, .XLS, or .CSV file here

    Controlled Import Rules

    Required base fields: Part Number, Description, Shop, and Aircraft Type. Shop must be one of the 5 TC shops. TAT (Days) is optional and must be a whole number. Max Capability is set from the costs: the highest stage with any cost filled. Leave a stage empty when the component cannot reach it, or type 0 for no cost. Total columns are optional; if filled, they must match the stage's costs. Costs are imported exactly as Excel displays them (text cells as 1.234,56); a cell showing "-" counts as empty. Duplicate Part Numbers inside the same file are flagged before import.

    Recommended flow: prepare data in the standard template before onboarding a large component database.
